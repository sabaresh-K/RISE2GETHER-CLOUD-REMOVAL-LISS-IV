The Challenge

High-Resolution Cloud Obscuration

Why traditional optical remote sensing struggles to capture persistent ground realities.

ISRO's LISS-IV sensor aboard Resourcesat provides exceptional high-resolution optical imagery at 5.8 meters. This detail is crucial for monitoring micro-level changes in agriculture, land use, and forestry.

However, persistent cloud cover frequently obscures critical scenes, rendering up to 60% of optical data unusable in tropical regions. This leaves massive temporal gaps in GIS analysis.

Existing restoration techniques either use simple spatial interpolation which blurs textures, or rely on temporal optical averages which fail during rapid changes (e.g., floods). We need a model that reconstructs details physically, not statistically.

Technical Pipeline

System Architecture

The end-to-end multi-sensor fusion and deep reconstruction pipeline.

01

Data Acquisition

LISS-IV Input

5.8m spatial resolution optical bands (G, R, NIR)

LISS-IV Imagery

Acquires high-res optical profiles. Crucial for land analysis but frequently obscured by tropical cloud cover.

Sentinel-1 SAR Input

C-band microwave radar (VV/VH dual-pol) data

Sentinel-1 SAR

Radar backscatter penetrates clouds, recording surface roughness, soil moisture, and physical layouts.

02

Preprocessing

Preprocessing Unit

  • Geo-alignment & co-registration
  • Radiometric normalization
  • Cloud & shadow mask generation
Preprocessing

Aligns LISS-IV and SAR grids. Normalizes pixel variables and extracts shadow/cloud layers via band thresholds.

03

AI Processing

AI Processing Unit

  • Cloud detection module
  • SAR-guided CycleGAN model
  • Feature fusion & refinement
AI Core (CycleGAN)

Uses dual generators to reconstruct hidden optical bands from SAR structural features, mapping details with high fidelity.

04

Output Layer

Output Unit

  • Cloud-free GeoTIFF generation
  • Quality metrics calculation
  • GIS-ready product layers
Output Generation

Assembles clean patches back into WGS84 coordinates. Runs validation metrics (PSNR, SSIM, SAM, RMSE) for GIS mapping.

Key Features

Engineered for Geospatial Rigor

Not just an image editing tool, but a highly accurate scientific reconstruction engine.

LISS-IV Resolution

Maintains the native 5.8m pixel spacing without introducing synthetic artifacts.

Multi-Sensor Fusion

Blends optical reflection with C-band radar backscatter for structural fidelity.

CycleGAN Architecture

Unpaired image-to-image translation guarantees structural consistency across domains.

Georeferenced Output

Retains all coordinate system metadata (UTM/WGS84) for GIS integration.

Quality Validated

Outputs verified via PSNR, SSIM, SAM, and RMSE relative to ground truth.

GPU Accelerated

Optimized PyTorch inference allows rapid patch-wise scene recovery in seconds.
